# Initial Concept
Establish a standardized, centralized, and scalable Angular application template with enterprise SSO integration and modern tooling (Angular 21, Tailwind CSS, ESLint, Vitest).

# Product Guide

## Scope
**This project serves as a standard Angular Starter Template (`template-app`).** It provides the foundational boilerplate, corporate SSO authentication flow, layout structure, and build/lint/test configurations for newly developed frontend applications.

## Target Users
Developers creating new Angular web applications within the organization.

## Features
- **Modern Angular**: Standalone components, Signals, Router.
- **Corporate SSO Integration**: Pre-integrated `@inx/inx-auth-lib` and JWT interceptor.
- **Tailwind CSS**: Pre-configured utility-first styling.
- **Vitest & ESLint**: Fast unit testing and code quality tooling.
- **Scaffolding Tool**: `scaffold.ps1` for rapid project provisioning.
